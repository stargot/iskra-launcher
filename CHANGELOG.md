# Changelog

Даты — YYYY-MM-DD. Версии — SemVer; суффикс `-alpha.N` — ранние сборки для смелых.

## [0.1.0-alpha.1] — 2026-10-02

Первый публичный выпуск.

### Добавлено

- **Поиск**: приложения (меню «Пуск», рабочий стол, Scoop), файлы пользовательских
  папок (индекс обновляется сам), разделы «Параметров» Windows, калькулятор и
  конвертер единиц прямо в строке, системные команды (блокировка, выключение
  экрана, сон, перезагрузка, завершение работы, очистка корзины), веб-фолбэк.
  Пустой запрос — недавние и частые приложения.
- **История буфера обмена**: текст, изображения (до 20 МБ) и скопированные файлы;
  история переживает перезагрузку; поиск по истории, закрепление (`pin`), дедуп
  со счётчиком `×N`; лимиты 1000 записей / 200 МБ, старые незакреплённые
  вытесняются; вставка в активное окно по `Enter`; тумблер мониторинга и
  исключения по программам в настройках.
- **Сниппеты**: имя, тело и ключевые слова; находятся в общем поиске, `Enter` —
  скопировать и вставить в активное окно.
- **Настройки**: горячая клавиша (`Alt+Space` по умолчанию), автозапуск, тема,
  мониторинг и исключения буфера обмена, сниппеты.

### Известные ограничения

- Только Windows 11.
- Вставка в окна, запущенные от имени администратора, не доходит (ограничение
  Windows UIPI).
- Альфа: формат хранимых данных может меняться между выпусками.
- Автообновления нет — новый выпуск скачивается вручную.
